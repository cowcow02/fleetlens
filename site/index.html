Start with the right surface

Two products, one data model.

The local dashboard is the default. Team Edition adds a shared server without changing where raw transcripts live.

Local Edition

Private dashboard on one machine

Install the npm CLI, run fleetlens start, and open localhost. The parser reads supported agent history and the daemon records plan snapshots in ~/.cclens.

no databaselocalhostmulti-agent

Team Edition

Self-hosted shared rollups

An admin deploys the server and Postgres. Members pair their local daemons, select projects, and send daily and rich aggregates - never raw prompts or assistant output.

Postgresinvite pairingself-hosted

The platform loop

From transcript to operating signal.

Each layer has a narrow job. That keeps local parsing useful on its own and makes the server boundary explicit.

01

Observe

Read JSONL and provider-local session history as agents work.

02

Normalize

Map Claude Code, Codex, Gemini, Grok, and other sources to common session shapes.

03

Analyze

Compute agent time, projects, daily activity, PR signals, cost, and concurrency.

04

Enrich

Build day-scoped entries and optional local AI digests from those derived inputs.

05

Share

When paired, send selected rollups to the Team Edition server.
