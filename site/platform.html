Fleetlens / Platform

A narrow pipeline with a wide view.

Fleetlens keeps raw agent history at the edge, converts it into common session data, and lets each surface consume the smallest useful representation.

Repository shape

Where the responsibilities live.

The monorepo is organized so pure parsing stays reusable while filesystem and network concerns sit at the edges.

packages/parser

Pure data model

Agent adapters, transcript parsing, presentation rows, session types, project identity, daily activity, cost, and concurrency analytics. The /fs entry point contains Node-only scanners.

packages/entries

Day-scoped work units

Builds one Entry per session and local day, computes deterministic signals, enriches entries locally when enabled, and composes day, week, and month digests.

apps/web

Personal dashboard

Next.js App Router pages read the local registry per request. A shared event stream refreshes session and usage surfaces when local files change.

packages/cli

Operator surface

Bundles the parser, web standalone output, and detached daemon worker into the published fleetlens binary.

packages/team-server

Shared rollups

Next.js server with Postgres-backed auth, teams, groups, integrations, insights, member commands, and ingest routes.

deploy/

Self-hosted paths

Railway template, Google Cloud installer, Docker Compose, and AWS Terraform describe the server's infrastructure choices.

Core semantics

The numbers have a point of view.

Fleetlens is intentionally opinionated about how agent work should be summarized.

Agent time, not wall clock

Timestamped events are split into active segments. A gap over three minutes is treated as idle, so the headline duration approximates time the agent was actually working.

Canonical projects

Worktrees fold into the parent repository. A worktree session remains discoverable but contributes to one project rollup, with worktree count retained for context.

Every local day touched

Sessions spanning midnight contribute to each local day they touch, clipped by segment duration. Day, week, and month surfaces therefore agree at boundaries.

Concurrency bursts

Short overlaps under one minute are dropped as noise. Nearby overlaps within ten minutes merge into a burst; same-project and cross-project bursts get different visual signals.
