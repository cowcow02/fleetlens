Fleetlens / Get started

From zero to a local dashboard.

The local path is deliberately small: install the CLI, start the server and daemon, then run an agent session.

1. Install the CLI

Fleetlens is published as the lowercase npm package and command fleetlens. Node.js 20 or newer is required.

npm install -g fleetlens
fleetlens version

2. Start the local services

fleetlens start launches the local Next.js server and the detached usage daemon together. Add --open to launch the browser.

fleetlens start
# or
fleetlens start --open
Default address

Open http://localhost:3321. Use fleetlens start --port 4400 or CCLENS_PORT=4400 if the default port is busy.

3. Run your normal agent workflow

Fleetlens watches the local transcript roots used by supported agents. It does not need a separate import step. The dashboard refreshes its server-rendered data when session files or usage state change.

The Overview page is the first checkpoint: sessions, agent time, tools, concurrency, code changes, cost, heatmap, and daily activity.

4. Learn the navigation

PageUse it for
/Overview metrics and recent activity.

/teamPairing and sync scope for Team Edition.

5. Confirm the daemon

fleetlens status
fleetlens daemon status
fleetlens daemon logs

The daemon writes snapshots and logs under ~/.cclens. Transcript analytics work without a usage snapshot; plan meters require the provider's local auth or configured credentials.

6. Stop or update

fleetlens stop
fleetlens update

stop manages both local services. update installs the latest CLI and restarts stale services so the dashboard and daemon use the same bundle.
