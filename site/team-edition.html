Fleetlens / Team Edition

Shared visibility without centralizing raw sessions.

Team Edition is the self-hosted server layer. It stores membership, rollups, usage history, integrations, and reports while local machines retain transcript authority.

Admin setup

Pick an infrastructure path.

All supported paths run the same Next.js team server and Postgres-backed data model. The tradeoff is operational control, not product behavior.

Railway

Fastest first deployment

The repository includes a one-click template that provisions the team server and Postgres with the core variables wired together.

Google Cloud

Cloud Run + Cloud SQL

The Cloud Shell installer provisions Cloud Run, Cloud SQL Postgres, Secret Manager, and the scheduler path with a preflight confirmation.

Docker Compose

Run it on your host

Compose runs the team server, Postgres, and Caddy. Set the database password and base URL, then let Caddy terminate TLS when a domain is available.

AWS Terraform

Own the cloud topology

The module targets ECS Fargate, RDS Postgres, and an Application Load Balancer. Bring an existing VPC, subnets, DNS, and optionally an ACM certificate.

Pairing loop

Admin creates context; members choose scope.

01

Deploy

Bring the server and Postgres online with a stable HTTPS URL.

02

Claim

The first account becomes admin of the first team.

03

Invite

Create an invite or device token from server settings.

04

Pair

Run fleetlens team join on each member machine.

05

Sync

Select projects, then let the daemon push rollups.

Member commands

fleetlens team join https://your-fleetlens.example <invite-token>
fleetlens team status
fleetlens team sync

The join flow opens the browser onboarding page so the member can select projects. For a non-interactive first sync, add --no-browser. The local Team page shows the server, team slug, pairing state, selected projects, last pushed day, and latest usage snapshot.

What the server receives

PayloadWhy it existsScope
Daily rollupAgent time, sessions, tools, turns, token totalsSelected projects and local day
Rich rollupWorking shape, skills, subagents, long turns, plan mode, tool errors, PRs, commits, pushesDerived project labels and counts
Usage snapshotCurrent provider windows and reset timesPaired member
Enriched extrasOutcome, helpfulness, and goal-minute mix from local enrichmentSelected project rollups
Raw transcripts are not the sync contract.

Prompts, assistant responses, absolute paths, file contents, tool-call payloads, and excluded projects remain on the member machine. See the privacy model for the full boundary.
